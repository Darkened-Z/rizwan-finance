📋 One-Time Setup (~5 minutes)
  1. Go to supabase.com → sign in → New project
  2. In the left sidebar → SQL Editor → paste the SQL below → click Run ▶
  3. In the left sidebar → Project Settings → API
  4. Copy your Project URL and anon / public key
  5. Paste both fields below → click Connect ✅
SQL to run once in Supabase SQL Editor:
create table if not exists transactions (
  id text primary key,
  type text, amt numeric,
  cat text, "desc" text, date text
);
create table if not exists config (
  key text primary key, value jsonb
);
alter table transactions enable row level security;
alter table config enable row level security;
create policy "open" on transactions for all using (true) with check (true);
create policy "open" on config for all using (true) with check (true);
alter publication supabase_realtime add table transactions;
ⓘ Credentials stored in this browser only. Paste the same values on any device for real-time cross-device sync. Supabase free tier: 500MB database, 2GB bandwidth — more than enough for personal use.
